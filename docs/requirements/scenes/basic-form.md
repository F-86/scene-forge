# 基础表单（BasicForm）

## 场景描述

展示一个典型的新增/编辑表单，涵盖文本输入、选择器、单选、开关、文本域等常见控件。用于验证表单在不同预填数据状态下的布局表现，以及必填校验、错误提示的视觉效果。

## 触发条件

- 用户进入 `/scenes/basic-form` 路由
- 顶部 MockSwitcher 选择不同变体，表单预填数据随之变化

## 字段定义

| 字段 | 控件类型 | 必填 | 说明 |
|------|----------|------|------|
| `name` | 文本输入 | 是 | 姓名，最多 20 字 |
| `email` | 文本输入 | 是 | 邮箱地址，需符合格式 |
| `role` | 下拉选择 | 是 | 角色：管理员 / 普通用户 / 访客 |
| `gender` | 单选组 | 否 | 性别：男 / 女 / 不填 |
| `bio` | 文本域 | 否 | 个人简介，最多 200 字 |
| `active` | 开关 | 否 | 是否启用，默认开启 |

## Mock 数据变体

| 变体 key | 说明 |
|----------|------|
| `empty` | 所有字段为空（新建状态） |
| `single` | 仅填写必填字段 |
| `normal` | 所有字段均有值（编辑状态） |
| `large` | 同 normal，但 bio 为超长文本（验证文本域撑高） |
| `withEdge` | 边界值：姓名超长、邮箱格式错误、bio 恰好 200 字 |

## 功能需求

### 表单控件

- 文本输入框：带 placeholder，focus 时边框高亮
- 下拉选择器：使用原生 `<select>`，带默认空选项
- 单选组：横向排列，三个选项
- 文本域：最小高度 80px，字数统计显示在右下角
- 开关（toggle）：点击切换，视觉上有开/关状态区分

### 校验规则

- 提交时触发校验，不做实时校验
- 必填字段为空时，字段下方显示红色错误提示文案
- 邮箱格式不合法时，显示「请输入有效的邮箱地址」
- 有错误时，表单不提交，页面滚动到第一个错误字段

### 提交 / 重置

- 「提交」按钮：触发校验，校验通过后显示成功提示（Toast 或内联提示均可）
- 「重置」按钮：将表单恢复为当前 Mock 变体的初始值

## 预期行为

### empty 变体
- [ ] 所有字段为空，placeholder 正常显示
- [ ] 点击「提交」，必填字段均报错
- [ ] 修复错误后再次提交，显示成功提示

### single 变体
- [ ] 姓名、邮箱、角色有值，其余为空
- [ ] 直接提交不报错，显示成功

### normal 变体
- [ ] 所有字段有值，直接提交成功
- [ ] 修改任意字段后点「重置」，恢复为初始值

### large 变体
- [ ] bio 超长文本，文本域自动撑高，字数统计正确

### withEdge 变体
- [ ] 超长姓名显示完整（输入框不截断）
- [ ] 邮箱格式错误，提交时报校验错误

## 不在本场景范围内

- 异步提交（无真实接口）
- 文件上传控件
- 联动字段（字段 A 影响字段 B 的选项）
- 实时校验（仅在提交时触发）
