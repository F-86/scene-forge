# 数据表格（DataTable）

## 场景描述

展示一张多列数据表格，支持列头点击排序、状态标签、金额格式化等常见业务表格功能。用于验证表格在不同数据量、不同字段组合下的布局表现，以及排序交互的视觉反馈。

## 触发条件

- 用户进入 `/scenes/data-table` 路由
- 顶部 MockSwitcher 选择不同变体，表格数据随之变化

## 数据字段定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `string` | 唯一标识，展示为行号或 ID |
| `name` | `string` | 姓名 / 名称 |
| `email` | `string` | 邮箱地址，可能为空 |
| `role` | `string` | 角色（如「管理员」「普通用户」「访客」） |
| `status` | `'active' \| 'inactive' \| 'pending'` | 账号状态 |
| `amount` | `number` | 金额（分），展示时格式化为带千分符的元 |
| `createdAt` | `string` | 注册日期，格式 `YYYY-MM-DD` |

## Mock 数据变体

| 变体 key | 数据量 | 特殊说明 |
|----------|--------|----------|
| `empty` | 0 条 | 显示空状态占位 |
| `single` | 1 条 | 验证单行时表格不撑满、列对齐 |
| `normal` | 15 条 | 常规展示，三种状态均有分布 |
| `large` | 200 条 | 验证大量行时页面滚动、布局不崩坏 |
| `withEdge` | 8 条 | 超长姓名、超长邮箱、金额为 0、邮箱为空、状态均为同一种 |

## 功能需求

### 表格列定义

| 列 | 对齐 | 可排序 |
|----|------|--------|
| # （行序号） | 居中 | 否 |
| 姓名 | 左对齐 | 是 |
| 邮箱 | 左对齐 | 否 |
| 角色 | 左对齐 | 否 |
| 状态 | 居中 | 是 |
| 金额 | 右对齐 | 是 |
| 注册日期 | 右对齐 | 是 |

### 排序

- 点击可排序列的列头，切换「升序 → 降序 → 无排序」三态
- 当前排序列显示排序方向图标（↑ / ↓）
- 无排序态显示中性图标（⇅），颜色淡化
- 排序在前端对当前变体数据进行，不分页

### 状态标签样式

| status | 文案 | 颜色 |
|--------|------|------|
| `active` | 活跃 | 绿色 |
| `inactive` | 停用 | 灰色 |
| `pending` | 待审核 | 橙色 |

### 空状态

- 数据为空时，表格区域显示 EmptyState 组件
- 文案：「暂无数据」

## 预期行为

### empty 变体
- [ ] 表头正常显示
- [ ] 表格区域显示 EmptyState

### single 变体
- [ ] 仅一行数据，表格不撑满、行高正常
- [ ] 所有列对齐正确

### normal 变体
- [ ] 15 行数据完整展示
- [ ] 三种 status 均有出现，颜色对应正确
- [ ] 点击「姓名」列头，数据按首字母升序排列，图标变为 ↑
- [ ] 再次点击，变为降序，图标变为 ↓
- [ ] 第三次点击，恢复原始顺序，图标变为 ⇅
- [ ] 金额列格式化为带千分符的元，右对齐

### large 变体
- [ ] 200 行数据正常渲染，无明显卡顿
- [ ] 页面可纵向滚动，表头不固定（本场景不做虚拟滚动）

### withEdge 变体
- [ ] 超长姓名超出时截断（ellipsis），不撑宽列
- [ ] 超长邮箱同样截断
- [ ] 邮箱为空时，该单元格显示「—」占位
- [ ] 金额为 0 时，显示「¥0.00」而非空

## 不在本场景范围内

- 分页 / 虚拟滚动（large 变体仅验证渲染，不要求性能优化）
- 行选择 / 复选框
- 列宽拖拽
- 服务端排序
