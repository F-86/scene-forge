## 场景描述

验证基础列表组件在不同数据量下的布局完整性，以及空状态、边界字段（超长文本、空字段）的 UI 表现。

## 触发条件

- 接口返回 0 条数据 → 空状态
- 接口返回 1 条数据 → 单条布局
- 接口返回 10 条数据 → 常规列表
- 接口返回 200 条数据 → 长列表滚动
- 接口返回含异常字段的数据（超长字符串、空字段）→ 边界值

## Mock 数据规格

| 字段          | 类型      | 说明                            | 取值示例                   |
|---------------|-----------|---------------------------------|---------------------------|
| `id`          | `string`  | 唯一标识                        | `"1"`、`"edge-1"`          |
| `title`       | `string`  | 主标题，必填                    | `"列表项标题 1"`           |
| `description` | `string?` | 副文本描述，可为空              | `"这是描述..."` / `undefined` |
| `tag`         | `string`  | 标签文字                        | `"重要"`、`"普通"`         |
| `tagColor`    | `string`  | 标签颜色（CSS 颜色值）          | `"#ef4444"`                |
| `avatarColor` | `string`  | 头像背景色（CSS 颜色值）        | `"#6366f1"`                |
| `avatarLabel` | `string`  | 头像内显示文字（首字或缩写）    | `"项1"`                    |
| `createdAt`   | `string`  | 创建日期，格式 `YYYY-MM-DD`     | `"2024-01-01"`             |

### 各变体数据量

| 变体       | 条数  | 说明                                     |
|------------|-------|------------------------------------------|
| `empty`    | 0     | 触发空状态 UI                            |
| `single`   | 1     | 验证单条时布局不异常                     |
| `normal`   | 10    | 日常验收主场景                           |
| `large`    | 200   | 验证长列表滚动性能                       |
| `withEdge` | 5     | 超长标题、无描述、超长描述、混合语言、极短文本 |

## 预期表现

### 空状态（`empty`）

- [ ] 展示居中的空状态区域，包含图标、主文案「暂无数据」和引导副文案
- [ ] 空状态区域有合理的内边距，不紧贴页面边缘

### 单条与常规（`single` / `normal`）

- [ ] 每条列表项包含：圆形彩色头像、主标题、标签、描述文字、创建日期
- [ ] 标签使用对应颜色的半透明背景和文字颜色
- [ ] 列表项有 hover 高亮效果
- [ ] 相邻列表项之间有 1px 分割线

### 大数据量（`large`）

- [ ] 200 条数据正常渲染，无明显卡顿
- [ ] 右侧内容区出现滚动条，Sidebar 不随内容滚动

### 边界值（`withEdge`）

- [ ] **超长标题**：单行显示，超出部分以「...」截断，不换行不撑开布局
- [ ] **无描述字段**：描述区域不渲染，布局不留空白间距
- [ ] **超长描述**：最多展示 2 行，第 2 行末尾以「...」截断
- [ ] **混合语言**：中英文混排显示正常，无乱码
- [ ] **极短内容**：极短标题和描述不影响整体行高和对齐

## 不在此场景范围内

- 不验证列表项的点击跳转逻辑（无真实路由）
- 不验证接口请求、分页加载等异步行为
- 不验证列表的增删改操作
- 不验证权限控制逻辑
