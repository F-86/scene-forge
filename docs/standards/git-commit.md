# Git 提交规范

## 一、提交信息格式

```
<类型>(<范围>): <描述>
```

## 二、类型说明

| 类型 | 说明 |
|------|------|
| `feat` | 新增场景或功能 |
| `fix` | 修复问题 |
| `mock` | 新增或修改 Mock 数据 |
| `refactor` | 重构，不影响场景行为 |
| `docs` | 文档变更 |
| `chore` | 工具 / 配置变更 |

## 三、提交示例

```
feat(scenes): 新增用户列表空数据场景
fix(UserList): 修复超长文本溢出未截断的问题
mock(UserList): 补充超长文本边界数据
refactor(mock): 提取公共工厂函数至 mock/factory.ts
docs(requirements): 更新空列表场景验收清单
chore: 升级 Vite 至 6.x
```

## 四、注意事项

- 描述使用中文，动词开头，简洁明确
- 范围对应 `src/scenes/` 下的目录名或模块名
- 单次提交只做一件事，避免将多个场景变更合并提交
