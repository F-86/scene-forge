# docs/

项目文档目录，分为规范文档和运行时记录两类。

## 目录结构

```
docs/
├── branches.md          # 分支记录：所有 scene / combo / exp 分支的登记表
└── standards/           # 规范文档：代码、Git、测试、文档等各项规范
```
